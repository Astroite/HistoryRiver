## 6. 开发者走查发现

### 已修复

1. **装饰粒子呈方形块状**：初版近景点精灵削弱“光点/悬丝”语义；改为带圆形衰减的点着色器。
2. **全史远景河体过细**：初版容易被看成一条微弱星尘；在 S0 单独提高点尺寸与光强，保持切片状态不过曝。
3. **Windows 启动脚本不兼容环境变量写法**：改为跨平台 `vinext` 命令，环境配置由 Vite 配置维护。

### 尚待开发者自验

2. C-02/C-05：记录事件进入、人物聚焦和返回路径，确认窗口与完整人生轨迹连续；
3. C-03：对比事件前、中、后的固定视口，确认事件聚集是唯一视觉重心；
4. C-04/C-07：对比 S2、S3、S4，确认两类线可区分、思想关系证据类型可见；
5. C-06：录制接管导览、重播导览和返回总览的完整状态路径；
