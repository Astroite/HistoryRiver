- 该问题直接命中迭代风险“光污染”与 D-04 两类线辨识失败信号，不能只通过统一降低透明度处理。

### 调整

- 采用按状态渐进显影：入流隐藏思想线、事件环和山河；观事仅保留窗口附近的人生短轨迹及极弱关系提示；逐人显示选中者完整一生；溯源只强调当前思想关系；
- 人生短轨迹按当前事件参与者与外围上下文分层，降低外围线亮度；
- 抬高入流镜头，缩小人物点，降低近景河粒子与人民光海密度，并弱化观察窗口边框；
- 思想线改为方向一致的低弧度三次曲线，未选关系退出视觉竞争。
