# M2-02 UE5 式三维视口相机

> 状态：已完成并归档
> 开始日期：2026-07-20
> 产品阶段：P1——数据艺术场景的基础浏览能力
> 归档日期：2026-07-20

本迭代只为现有 Three.js 画面增加桌面端三维视口相机导航。交互规则对齐 UE5 编辑器透视视口，不增加任何可见 UI，不恢复自动播放、人物悬停、点击选中、详情、时间轴或 URL 状态。

## 核心原则

- 相机交互是视口基础设施，不改变人物、年度切片或视觉层的语义；
- 使用专用控制器复现 UE5 透视视口输入，不引入 `OrbitControls`；
- 没有拾取与选择，因此 `F` 聚焦当前作品整体，而不是虚构“已选对象”；
- 初始构图仍是 M2-01 已验收的基准构图，且相机不会自行移动。

## 完成结果

UE5 透视视口的鼠标导航、RMB 飞行键、滚轮调速、Alt 枢轴操作、作品聚焦、Pointer Lock 降级和生命周期清理均已实现。数据、类型、24 项单元测试、构建、2 项页面回归与 lint 全部通过；可见 UI 和人物/时间产品交互仍未进入运行时。
