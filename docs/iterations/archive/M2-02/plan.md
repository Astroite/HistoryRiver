# M2-02 迭代计划（已完成）

## 目标

在不恢复产品 UI 与数据对象交互的前提下，为整屏 3D 场景增加 UE5 编辑器风格的透视相机导航。

## 输入合同

| 输入 | 相机行为 |
| --- | --- |
| RMB + 拖动 | 自由环视 |
| RMB + W/S、A/D、E/Q | 朝视线前后、左右平移、沿世界坐标升降 |
| RMB + R/F | 沿相机局部坐标升降 |
| RMB + Z/C | 增大/减小视野角 |
| RMB + 滚轮 | 提高/降低飞行速度档位 |
| LMB + 拖动 | 前后移动并左右旋转 |
| MMB 或 LMB+RMB + 拖动 | 不旋转地平移相机 |
| 滚轮 | 按步长前后移动 |
| Alt+LMB / MMB / RMB + 拖动 | 围绕作品枢轴环绕 / 跟踪平移 / 推拉 |
| F | 聚焦作品整体 |

方向键、Page Up/Down 与数字键盘采用 UE5 文档列出的等价飞行键。Shift 在飞行时临时加速。右键环视优先请求 Pointer Lock，失败时保留拖拽降级路径。

## 范围

- 新增独立、可释放的相机控制器；
- 接入现有渲染循环并保持固定初始构图；
- 更新 CSS 光标/触控行为和无障碍说明；
- 更新 M2 设计、视觉和技术合同；
- 增加输入映射、相机运动、聚焦与生命周期测试。

## 明确不做

- UI、操作提示层、按钮、设置面板；
- Raycaster、人物悬停、点击选择、标签或详情；
- 自动镜头、惯性巡航、时间播放；
- 触屏手势、正交视口、对象变换 Gizmo；
- 保存镜头位置到 URL 或本地存储。

## 验收

1. 所有表内输入按约定改变相机，松开后不会继续飞行；
2. 页面加载后相机保持基准构图，只有用户输入才能改变；
3. 无 UI、无拾取、无播放产品逻辑；
4. 控制器释放后移除监听并退出本场景发起的 Pointer Lock；
5. 数据校验、类型检查、单元测试、构建、页面回归和 lint 通过。
