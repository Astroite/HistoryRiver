## 6. 开发者走查发现

### 已修复

1. **装饰粒子呈方形块状**：初版近景点精灵削弱“光点/悬丝”语义；改为带圆形衰减的点着色器。
2. **全史远景河体过细**：初版容易被看成一条微弱星尘；在 S0 单独提高点尺寸与光强，保持切片状态不过曝。
3. **Windows 启动脚本不兼容环境变量写法**：改为跨平台 `vinext` 命令，环境配置由 Vite 配置维护。
4. **海洋只有同宽细线与均匀微点**：保留统一流场，增加约 8% 屏幕空间潮脊、全海势值相位、粒子生命周期/尺寸层次、冷色浪谷和深海微尘；首次选择性辉光走查发现右侧白金波峰过曝，随后提高阈值并压低普通粒子的 HDR 能量，复测不再形成白色光雾。
5. **海洋 Bloom 与正常 pass 共用 HDR 输出**：为四类海洋材质加入 `uBloomPass` 并由后期可靠切换；普通输出压到全局 Bloom 阈值以下，只在选择性 pass 写入超级光刃、彗星头和焦点星芒 HDR。一次汇流 alpha 放大调校造成左右白雾，已回退为受基础透明度约束的局部 glint。
