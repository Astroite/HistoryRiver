## 核心原则

- 人物是第一记录单元，事件只作为人物年度轨迹的可选依据或注释；
- 每个有效历史年都有一个切片，但切片允许明确记录“尚无策展数据”，不能为了连续画面捏造人物；
- 有史料的观察与逐年派生记录分层保存；未知就是未知，插值必须标明来源和规则；
- 河流表达的是当前数据库中的人物轨迹与策展覆盖，不得暗示为人口总量或客观历史重要度；
- 正式运行时只保留视觉与必要渲染基础，不保留 UI、自动播放、悬停、选择或详情产品逻辑。
