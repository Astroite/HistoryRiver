# 《落九川》历史地理背景说明

> 状态：M2 独立艺术背景 v0.2
> 重要：本模型不是人物轨迹数据库、疆域地图或精确行政边界

## 1. 当前语义

地理体积是天河的低亮背景参照。稀疏人工关键帧提供区域权重和不确定度，黄河、长江与抽象山脉提供弱约束；每个有效历史年生成一条同拓扑闭合轮廓，并由纵向纤维连接相邻年份。

它只表达抽象历史空间随时间的体量变化，不回答某年精确国界，也不提供人物位置。人物位置来自年度人物数据库中的观察与派生记录，两套语义严格分开。

## 2. 纪年

地理背景与人物数据库共用 `historicalYears()` 和 `historicalYearToY()`：公元前 2700 年至 1949 年共 4,649 层，跳过公元 0 年。相邻 BCE/CE 层由 `yearIndex` 连续连接。

## 3. 当前实现边界

- `geography-volume.ts` 保存人工关键帧、插值、山河约束与几何构建；
- `history-geography-visuals.ts` 只以固定透明度渲染完整体积与纵向纤维；
- 已删除焦点年份、二十年邻域和体验状态驱动显隐；
- 所有关键帧仍标记 `prototypeOnly`，不能作为正式历史地理数据发布；
- 人物策展覆盖不会反向改变地理轮廓。

## 4. 研究来源边界

| 来源 | 可支持的研究 | 当前处理 |
| --- | --- | --- |
| [China Historical GIS](https://gis.harvard.edu/china-historical-gis) | 统一王朝后的行政变化节点 | 仅研究，不提交受限原始/派生几何 |
| [OpenHistoricalMap](https://www.openhistoricalmap.org/about) | 开放时间标签历史要素 | 单要素核查许可后方可引用 |
| [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) | 概化河流、地形和海岸方向 | 只提炼低精度骨架，不复制地图外观 |

当前人工权重尚未达到正式来源化门槛。未来数据化必须逐关键帧保存来源、日期、许可、覆盖范围和不确定度理由，并允许多政权/多中心空间，不强行合并为单一国界。

## 5. 视觉约束

地理背景必须低于人物丝线和汇流光核，不显示焦点边界、行政网格或透明地图面板。资料不足的时期只能提高不确定度或减弱边缘，不能用连续动画伪装成逐年测量。
