# 《落九川》视觉设计基线

> 状态：视觉基线 v0.2（P0 已落地）  
> 更新：2026-07-16  
> 适用：P0 场景重塑、镜头与光效实验；不作为正式历史内容依据  
> 参考输入：[history-river-hero-02-ethereal.png](./reference/history-river-hero-02-ethereal.png)（16:9）

## 1. 结论

《落九川》不应被设计成一块深色数据看板。它首先是一处无边界的夜空：历史从云雾深处垂落为巨大的光瀑，在近处汇成有潮汐感的人民光海。人物、事件和关系是这片光中逐层被看见的结构，而不是先用面板、按钮和说明文字解释的内容。

本阶段的画面目标是 **“玄夜、天河、光海”**：黑不是背景色，而是让云、丝线与微光拥有纵深的空间；金色不是装饰色，而是历史流入当下的温度；蓝灰不是科技感，而是九天云气与遥远时间。

## 2. 参考图解读

参考图提供的是空间、光和情绪的准则，不是需要逐像素复刻的素材。

| 观察 | 设计含义 | 落九川的转译 |
| --- | --- | --- |
| 画面上半部近乎无边界的暗云与星尘 | 先建立“九天”而非舞台布景 | 远处源头不出现实体入口、建筑或徽标；用低对比云体、稀疏微粒与深黑留白建立高度。 |
| 画面偏右的巨大垂直光瀑 | 历史有方向和重力，但没有硬边界 | 时间河保持由上向下的势能；丝线在远景先聚成瀑，靠近观察窗才分解出人物。 |
| 瀑布从冷白、蓝灰过渡到暖象牙白 | 冷暖变化来自光的旅程，不来自 UI 配色 | 上游以月白与雾蓝为主，落到当下逐渐出现暖金和象牙白；同一条河内不出现高饱和霓虹。 |
| 下半部是大面积、向镜头延伸的流动光海 | “今天”应是有包裹感的现场，不是时间轴末端 | 1949 内容边界落入前景光海；光海向画外延续，代表人民与仍在发生的历史。 |
| 光点沿流向形成纤细、有组织的纹理 | 细节应服从大流势 | 粒子、人物丝线和事件扰动都沿河势组织；拒绝均匀撒点、随机闪烁和满屏同亮度。 |

### 2.1 画面构图

- **基准画幅**：桌面端 16:9；首屏以全画幅场景呈现。
- **地平 / 汇流带**：位于画面高度约 58%–66%，不画成硬直线；由雾、流光和浅层水纹共同形成。
- **主瀑位置**：中心可略偏右，约占画面宽度 18%–28%；允许整体有轻微 S 形偏移，避免“垂直坐标轴”感。
- **上方留黑**：至少保留 30% 的低信息暗部，让光瀑从不可见的九天而来。
- **前景光海**：占画面下方约 35%–45%，以横向展开的水纹承接垂直瀑流；亮度低于核心汇流点，面积大于它。
- **视觉重心**：唯一最高亮度在“瀑流触地 / 入海”的汇流处；第二亮度是流向前景的细丝，云体和天空必须退后。

## 3. 视觉原则

1. **先感到河，再读到数据。** 第一秒看见的是一股从天而降的历史势能；人物名称、年份、关系证据只在主动探索时出现。
2. **少而深，不多而亮。** 大面积必须足够暗；亮部应以光核、光纤和极稀疏星尘分层，而非靠全屏蓝色粒子填满。
3. **丝线有生命，不是网格。** 人物轨迹应有成束、分叉、汇流、消隐和轻微流速差；不得呈现为机械等宽线段或整齐平行的瀑布条纹。
4. **云是空间介质，不是贴图背景。** 云雾遮蔽远处、托住源头、接住汇流；它应随相机产生层次变化，不能是一张固定的半透明平面。
5. **当下是温暖的，古远是克制的。** 从上至下完成“雾蓝 → 月白 → 象牙暖金”的能量迁移。暖色只在汇流及少量关键人物 / 事件的局部出现。
6. **界面服从静默。** 首屏和自动导览期间不常驻任何标题、面板、图例、指标或按钮。信息在用户操作后短暂出现，停止操作后退场。

## 4. 色彩与明度系统

以下为从参考图提炼的工程起始值，需在 HDR / Tone Mapping 环境中以截图为准微调，而非把十六进制颜色直接当成最终像素色。

| 令牌 | 起始色 | 用途 | 使用约束 |
| --- | --- | --- | --- |
| `void` | `#02070B` | 深空、画面边缘、远景底色 | 覆盖大部分非主体区域；不能纯黑死掉，保留极微弱冷色层次。 |
| `night-blue` | `#0C1823` | 远云与天空层 | 大面积、低对比；避免青色发亮。 |
| `cloud-slate` | `#31485D` | 中景云体、远处体积光 | 只作轮廓和背光，透明度优先于高亮。 |
| `celestial` | `#A9C5DC` | 上游冷光、细丝高光 | 使用窄而稀的线性高光，不能铺成实心蓝。 |
| `river-blue` | `#789CB9` | 光海流纹、次级流向 | 低饱和、低于核心亮度。 |
| `ivory` | `#F3EBDD` | 瀑流核心、雾中高光 | 面积小，带 Bloom；避免整片纯白。 |
| `memory-gold` | `#E7CCA0` | 汇流温度、极关键节点 | 只占亮点中的少量比例；不做金属 UI 边框。 |

建议的亮度层级（从高到低）为：汇流光核 > 人物 / 事件的少量强调点 > 瀑流丝线 > 前景流纹 > 云体边缘 > 天空星尘 > 背景。任何时刻都应保留至少 70% 的暗部，让 Bloom 有可感知的呼吸空间。

## 5. 场景材质与动效

### 5.1 三层空间

| 层级 | 组成 | 行为 |
| --- | --- | --- |
| 九天层 | 深空、星尘、缓慢卷动的高空云 | 星尘密度极低；云体遮住源头的边界，运动速度几乎难以察觉。 |
| 天河层 | 人物丝线、分层粒子、体积雾、源头辉光 | 远景聚束并向下加速；进入观察区后逐渐分离，宽度与辉光才显影。 |
| 光海层 | 流动光纹、低空雾、汇流波、近景微粒 | 横向扩散并向镜头延展；不使用镜面水面，表现为由无数人和故事汇成的光。 |

### 5.2 光效规则

- Bloom 只服务高能量细节：丝线边缘、汇流光核和少量关键节点。阈值应足够高，避免整片天空泛白。
- 以两到三层不同频率的微粒代替一层“大粒子雨”：远处如星尘，中景如光纤碎片，近处如贴地流纹。
- 用低频噪声改变云和光海的密度，用曲线场或河势控制粒子方向；不要让随机数同时控制位置、颜色和闪烁。
- 相机移动时，近景雾、远景云、丝线和光海必须产生不同速度的视差。
- 动画节奏以“缓慢蓄势—穿入—释放—回落”为一轮。默认状态不做持续抢眼的脉冲，遵从 `prefers-reduced-motion`。

### 5.3 人物、事件与关系的视觉语法

| 对象 | 远观 | 近观 | 强调方式 |
| --- | --- | --- | --- |
| 人物 | 汇入天河的一根光纤 | 可读为连续生命轨迹，局部宽度反映影响 | 以“更清晰、更温暖、微微变宽”强调，不使用大号圆点或描边。 |
| 事件 | 河势中一次局部增密与旋涡 | 以雾中聚束、环流或短暂亮起的群集呈现 | 不做常驻发光圆环；高亮后应自然回到河势。 |
| 思想关系 | 在大尺度上几乎隐入河流 | 两条轨迹之间的一次细而克制的跨越 | 依据类型改变连续 / 虚断 / 衰减，颜色比人物丝线更淡。 |
| 历史切片 | 光瀑中不露痕迹 | 以一段更清晰的空气、雾和地理方位展开 | 不能是透明立方体、网格或数据面板。 |

## 6. 镜头分镜与体验状态

| 状态 | 镜头与构图 | 光与密度 | 用户感受 |
| --- | --- | --- | --- |
| 全史远观 | 站在光海边，仰望从暗云垂落的天河；主瀑占画面但不顶满画幅 | 云深、丝线未分辨、汇流最暖 | “历史比我更大。” |
| 入流 | 镜头沿河势接近，主瀑从整体分裂为多层光纤 | 冷白丝线逐渐可辨，雾产生明显视差 | “我正进入无数人的时间。” |
| 历史切片 | 镜头由斜视转为较高的斜俯视，河流在局部展开成山河方位 | 光海退到背景，局部人物和事件显影 | “一段时代在地理中发生。” |
| 人物聚焦 | 沿一根丝线移动，前后生命阶段逐段出现 | 被选人物仅比周围温暖 / 清晰一级 | “一个人也在长河中流动。” |
| 关系溯源 | 相机留足两条轨迹之间的暗部，让关系线跨越而过 | 关系线细、暗、带轻微延迟残影 | “思想能越过生命继续流。” |

切换原则：切换应以镜头、雾密度、丝线分合和色温变化完成；除非用户已主动索取信息，否则不要用标题卡、状态标签或进度条解释状态。

## 7. 未来界面原则（本阶段不实现）

本次原型应保持无 UI。恢复信息交互时，界面也不能回到“左右栏 + 顶部导航 + 底部控制台”的仪表盘结构。

- **首次信息只出现一个。** 用户悬停人物时，最多在邻近位置出现姓名与年代的一行低亮文字；离开后淡出。
- **控件由手势唤起。** 时间、维度、导览和设置在用户移动到边缘、按住特定键或主动暂停后出现；默认完全隐去。
- **内容采用浮层，不遮场景。** 史料、人物介绍和关系证据采用窄幅、半透明、可随时关闭的阅读层，避免固定两侧面板。
- **文字是注释，不是装饰。** 不使用伪古风印章、全大写英文字母、工程性能指标或常驻图例占据画面。
- **所有 UI 都可退场。** 闲置 2–3 秒逐步减弱；截图、导览和首次进入时必须保持纯场景。

## 8. P0 落地记录

视觉基线已经进入 P0 实现，当前场景不再是随机粒子柱或深色控制台：

- 首屏保持纯场景，常驻 HUD、面板、图例、性能栏和控制条均已移除。
- 天河由成束但不等距的曲线光纤、分层流动微粒与纵向雾光共同构成；装饰层在历史源头之上继续隐入云中。
- 前景改为从汇流点向镜头展开的冷暖光海，使用弯曲河道、断续光纤、粒子流和低空雾，而不是均匀圆盘点云。
- 天空加入稀疏星尘、源头云、中空侧云与地平云，利用多层 Sprite 的位置差形成视差。
- 色温完成“雾蓝—月白—象牙暖金”的纵向迁移，Bloom 只强化光纤核心、人物节点和汇流点。
- 透明观察立方体已取消；历史窗口改由局部清晰度、丝线分合和镜头变化表达。
- 事件发光圆环已改为旋转缓慢的点云聚集；人物节点缩小，思想关系颜色收敛到整体冷暖体系。
- 五个体验状态继续共享同一空间，并已分别完成 16:9 截图走查。开发检查可使用 `?view=river-overview`、`entering-window`、`slice`、`person-focus` 或 `relation-focus` 直接定位状态，不产生可见 UI。
- 后处理采用 ACES 色调映射与受控 Bloom；低动态偏好仍会停止环境流动和呼吸动画。

后续若进入 P1，可提升真正的体积云、局部光照和高质量 GPU 曲线，但这些属于精度升级，不改变本文件已经落地的构图、色彩和视觉语法。

## 9. 验收标准

- 16:9 首屏中没有标题、徽标、边框、按钮、图例、性能数据、面板或常驻文字。
- 观者在不阅读文字的情况下，能感到“云中垂落、近处汇流、向前延展”的单一大流势。
- 画面中最亮处稳定落在汇流区；云和背景不与其争夺注意力。
- 冷蓝、月白、象牙暖金形成连续过渡，不出现赛博霓虹、纯白大面积过曝或金色装饰框。
- 暂停截图时，粒子与丝线仍呈现可解释的流向、束流和空间层次，而非随机噪点。
- 进入人物或关系状态后，场景增强信息密度但不丢失“同一条天河”的总体印象。
