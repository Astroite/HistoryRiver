# 《落九川》视觉设计基线

> 状态：M3 观河体验层视觉基线 v1.2
> 更新日期：2026-07-23
> 参考图：[history-river-hero-02-ethereal.png](./reference/history-river-hero-02-ethereal.png)

## 1. 画面结论

《落九川》首先是一处无边界玄夜，而不是数据看板。历史从云雾深处垂落为天河，在近处汇入有潮汐感的人民光海。M2 保留 M1 已确认的天空、云雾、瀑流、河口、光海、色温、材质和后处理，同时让跨时代人物年度轨迹成为河体内部可追溯的数据丝线。

正式画面以既定构图开始，保留观河体验层（序章题字、纪年轴、人物识读、名录），没有自动镜头、焦点节点、事件点云或关系线。观看者可以用纯鼠标（左键环绕、右键/中键平移、滚轮推拉、双击回全景）离开初始机位浏览三维作品。

## 2. 初始构图

- 基准画幅为桌面 16:9；
- 上方保留大面积暗部和稀疏星尘，源头隐入云中；
- 主瀑略偏右，由上至下形成轻微弯曲；
- 汇流区位于画面中下部，是最高亮度；
- 人民光海横向铺满前景并向画外延续；
- 初始镜头位置和目标固定，只因 Resize 更新投影比例；没有用户输入时不移动；
- 相机交互不得改变光照、人物集合、年份、材质时间或数据语义；
- 双击回到整件作品全景，提供迷失后的返回路径，但不虚构对象选择状态。

## 3. 色彩与明度

| 令牌 | 起始色 | 用途 |
| --- | --- | --- |
| `void` | `#02070B` | 深空与画面边缘 |
| `night-blue` | `#0C1823` | 远云与天空 |
| `cloud-slate` | `#31485D` | 中景云体 |
| `celestial` | `#A9C5DC` | 上游冷光 |
| `river-blue` | `#789CB9` | 次级流纹 |
| `ivory` | `#F3EBDD` | 瀑流核心 |
| `memory-gold` | `#E7CCA0` | 汇流与当下温度 |

古远保持雾蓝与月白，接近当下逐渐转为象牙暖金。Bloom 只强化细丝和光核，大面积暗部必须保留。

## 4. 三层视觉

| 层 | 内容 | 数据语义 |
| --- | --- | --- |
| 九天 | 星空、源头云、中空云、地平雾 | 纯环境视觉 |
| 天河 | 装饰瀑流、年度地理纤维、人物年度丝线 | 只有人物丝线携带人物/年度 ID |
| 光海 | 潮脊、短丝、浪花、深海尘埃、汇流辉光 | 纯环境视觉，不代表人口单位 |

装饰粒子不得被描述为人物或史实。年度地理体积是独立艺术背景，不是疆域数据库。策展人物数量也不能控制整条河的总水量，否则会把资料密度误写为历史繁荣程度。

## 5. 人物年度丝线

- 一人一条稳定生命线；
- 相邻年度记录连接成线段；
- 线段顶点保留人物索引和 `yearIndex`；
- 领域决定低饱和主题色，策展视觉权重只影响显示，不进入事实层；
- 有观察的年度位置对线形产生克制偏移；
- 未知位置沿稳定艺术河道延续并降低透明度；这表示“人物处于活动范围但位置未知”，不是精确行迹；
- 正式数据没有观察支持时不生成地理移动；
- 环境流光可缓慢经过人物线，低动态偏好下冻结。

## 6. 环境动效

星尘、云雾、瀑流粒子、海浪、浪花和光核可以持续低频运动。这些运动不推进年份、不切换镜头、不改变人物集合，因此属于材质和环境动画，而不是自动播放。

动效遵循 `prefers-reduced-motion`：冻结主要流动和呼吸，但保留静态层次。Resize、设备质量档和资源释放属于渲染基础设施。

## 7. 观河体验层（v1.2 新增）

体验层是宣纸与展签的质感叠加在玄夜之上，不改变三层视觉的语义：

- 字体为宋体/衬线竖排，题字带冷光晕；朱砂朱印（`#A63A2C`）是唯一高饱和点缀，只用于题款与人物名印；
- 界面底色为深墨半透明（`rgba(4, 11, 16, 0.66)`）加背 blur，描边用 `memory-gold` 低透明发丝线；
- 纸墨颗粒以极低透明度（0.05）overlay 混合，只增质感，不污画面；
- 纪年轴居右，细如界尺；当前所望年份以金线刻度标记，随相机缓动；
- 人物志居左，如展签：名、异名、时代、领域、生卒、轨迹、纪年状态、入选理由、地点证据依次排布；
- 悬停名签、名录与底部操作提示均克制避让主瀑与汇流高光区；
- 体验层遵循 `prefers-reduced-motion`；序章可由首次输入退场，不自动推进任何内容。

## 8. 禁止回归

- 体验层退化为数据看板：大图例、性能栏、密集表格或常驻高亮面板；
- 以定时器推进视图或自动移动相机；
- OrbitControls、Raycaster 场景拾取（人物拾取使用屏幕投影采样，不引入 Raycaster 依赖）、或非相机/识读之外的键盘产品命令；
- 五种体验状态或 `?view=` URL；
- 模拟事件点云、思想关系线、焦点节点或详情语义；
- 用完整年度 JSON 直接膨胀客户端而不生成紧凑渲染产物；
- 把未知人物位置画成确定地图路线。

## 9. 验收

- 1920×1080 初始视口能清楚看到九天、天河、入海和光海，序章题字不夺河体主势；
- 未输入时构图不漂移；输入后可纯鼠标环绕、平移、推拉，双击回到全景；
- 无文字也能读出从高处落入当下的单一大流势；
- 汇流最亮，天空与背景不争夺注意力；
- 悬停人物丝线有暖金提亮，点取后金晕勾出该人生命线；
- 纪年轴标记年份随相机枢轴高度连续更新；
- 数据人物线融入河体，但能与纯装饰层在代码中区分；
- 低动态模式保持完整静态构图；
- 未知、传说与低置信数据不会获得比直接观察更确定的视觉表达。
